# Electricity Calculator

## Description
It is a calculator that helps you calculate how much electricity you consumed and how much you need to pay.

##  Version 1 - Original code without input validation
- Input: Accepts a customer's name and two meter readings
- Process: Calculates the consumption, the total bill, then displays both.
- Output: Customer's name, electricity consumption, and the total bill.
- Does not include input validation

## Version 2 - Code with input validation
- Input: Accepts a customer's name (but not empty names), accepts two meter readings with the previous meter reading having to be at least zero and the current meter reading having to be at least the previous meter reading's value.
- Process: Calculates the consumption, the total bill, then displays both.
- Output: Customer's name, electricity consumption, and the total bill.
- Now includes input validation
